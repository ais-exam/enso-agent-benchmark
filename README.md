# SciExam for ENSO website

Project page for *SciExam for ENSO: Can AI Agents Build Climate Models?*, part of [AI's Exam](https://ais-exam.github.io/).

Live site: https://ais-exam.github.io/enso-agent-benchmark/

Static site, no build step. `index.html` is the main page, `results/` holds the full results and the model equations, and `ersst_data.js` is the sea surface temperature data behind the live map. Code and data for the benchmark are in [SciExam-ENSO-code](https://github.com/ylzhang2447/SciExam-ENSO-code).
